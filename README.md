# Budget App familiar

App de presupuesto compartida para el hogar, para web y móvil (PWA), con manejo de colones y dólares y conversión automática según el tipo de cambio del BCCR.

## Estado

En planificación. Ver [docs/PLAN.md](docs/PLAN.md).

## Estructura

```
app/        Frontend (React + TypeScript + Vite, PWA)
supabase/   Migraciones de base de datos y Edge Functions
docs/       Plan y documentación del proyecto
```

## Stack

- React, TypeScript, Vite
- Supabase (Postgres, Auth, Realtime, Edge Functions)
- Vercel o Netlify
- GitHub Actions
